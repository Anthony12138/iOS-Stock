跌停分析 · 反核与超跌反弹 · 主板

把当日主板跌停股全部拉出来，按 撬板强度 26%（开板次数 / 封单占流通市值 / 封单相对成交额）· 超跌位置 20%（60 日分位 / 20 日跌幅 / 偏离 MA20）· 量能换手 18%（恐慌盘有没有换出去）· 封单压力 14%（封单越大越难撬）· 板块环境 12%（同行业跌停家数 / 同行业是否仍有涨停）· 资金承接 10% 打分。
分三栏（点击栏目标题可折叠）：当日盘中买入（第一栏：跌停价已被撬开、现价离开跌停价，盘中就能动手）/ 可博地天板（封单薄、反复撬开、换手充分，博翻红封板或次日反核）/ 尾盘买入博弈次日（仍压在跌停价上，等尾盘看封单被吃掉的迹象再博次日反核）， 以及不参与（一字死封、连续跌停、高位崩塌）。
封单额、开板次数、连续跌停天数、所属行业均取自交易所盘后公开数据；「同行业仍涨停」用来区分错杀与板块性出货。
